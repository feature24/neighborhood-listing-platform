# Neighborhood Listing Platform

A simple neighborhood platform featuring property listings, neighborhood sponsors, and voice help.
## Features

- Listings
- Neighborhood Sponsors
- Voice Help

## Technology

- Next.js
- TypeScript
- Tailwind CSS
- Accessible HTML
- Git and GitHub

## Live Site

https://neighborhood-listing-platform.vercel.app

## Verification

The project was tested locally with:

- npm run dev
- npm run lint
- npm run build

The production build and lint checks passed successfully.
